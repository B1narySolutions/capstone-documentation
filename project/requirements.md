# Requirements

Source: the sponsor's project specification (sponsor: Kevin Hallquist). Ask Rocco for the PDF.

## Must have
- Three amp types, as close as possible to a Fender '65 Twin Reverb, Vox AC30 and Marshall 800
- Microprocessor control and a touchscreen UI
- 1/8" headphone output that turns off the speaker amp
- 1/8" AUX input
- Rechargeable battery, 5-6 hours of use
- 5-10 W final amp stage
- Speaker enclosure with speaker(s)

## Second level: effects
Priority order: Reverb, Delay, Distortion/Overdrive, Compression, Chorus, Noise gate.
Any combination can be on at once. Controls for each:

| Effect | Controls |
| --- | --- |
| Compression | Level, Attack, Sustain |
| Distortion | Level, Gain, Tone |
| Chorus | Mix, Rate, Depth |
| Delay | Mix, Time, Feedback |
| Reverb | Mix, Decay, Tone |

Parameter ranges are still TBD.

## Stretch goals
- Footswitch (wired or wireless) to turn each effect on and off
- USB-C for charging and as a USB audio interface

## Deliverables
- Working amp at the 26/27 Capstone EXPO
- Open-source repo with everything needed to rebuild it
- CAD, PCB files, specs, technical description, test results, user manual, presentation materials

## Course deadlines (student manual)
- **Week 8:** assembled PCB plus a test plan (sec 36.2.1). It doesn't have to work yet.
- **Week 14 (PoC demo):** working PCB, with features, how they were tested, results, and number of revisions (sec 39.1.4).
- Free board orders: 2 layers, under 100 x 100 mm, team and designer names on the silkscreen (sec 11.1).
