# Test plans

## What the course requires

**Deadlines**
- **Week 8 (50 pts):** assembled PCB plus a test plan for what we'll measure and how (sec 36.2.1, p. 306).
- **Week 14, PoC demo (50 pts):** working PCB. Show expected features, how we tested them, the results,
  and how many revisions it took (sec 39.1.4, p. 312). Full points if the board "substantially meets" our
  own requirements, so write them carefully.

**The plan defines** (sec 30, p. 280)
- What "working" means for the board (a short board requirements list)
- Which tests we'll run and what counts as a pass
- What we'll demonstrate and which numbers we'll measure

**Each test answers** (sec 21.3, p. 207)
1. Test name and the risk it targets
2. Which requirement it checks, and why it isn't trivial
3. Which modules are tested
4. How this setup differs from the final EXPO hardware
5. Inputs and outputs, what's measured and how (a sketch of the expected plot helps)
6. Numbers for pass or fail
7. Expected results
8. What the result means for the design, the decision we'll make, and Plan B if it fails

Keep it short: a few slides of bullet points is enough. Show it to the TA early for feedback.
